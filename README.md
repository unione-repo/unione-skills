# UniOne agent skills

Skills for AI coding agents (Claude Code, Cursor, Codex, Copilot, Gemini CLI, …) in the
[Agent Skills](https://agentskills.io) format: integrate the UniOne transactional email Web API, write email templates,
get to the inbox and migrate from other providers.

## Install

```bash
npx skills add unione-repo/unione-skills
```

Claude Code plugin: `/plugin marketplace add unione-repo/unione-skills`, then `/plugin install unione@unione-skills`.

## Skills

| Skill | For |
|---|---|
| [`unione`](skills/unione/SKILL.md) | The UniOne Web API: sending, templates, webhooks, domains, sandbox, SDKs |
| [`unione-email-templates`](skills/unione-email-templates/SKILL.md) | HTML emails for mail clients, template engines, the visual editor |
| [`unione-email-best-practices`](skills/unione-email-best-practices/SKILL.md) | Deliverability, compliance, list hygiene, reliability |
| [`unione-migrate`](skills/unione-migrate/SKILL.md) | Move from SendGrid, Mailgun, Resend, Postmark |

## MCP server

The plugin registers the hosted UniOne MCP server `https://mcp.unione.io/mcp` (Streamable HTTP, OAuth sign-in or an API key): tools for the user's account — domains, sending, templates, webhooks, suppressions.

## Prerequisites

- A UniOne account: https://cp.unione.io/en/
- An API key in `UNIONE_API_KEY`

## Generated

The skills are generated by the UniOne team from the UniOne Web API spec, like the SDKs: do not edit this repository by
hand, the next release replaces it. Report problems in the issues of https://github.com/unione-repo/unione-skills.
